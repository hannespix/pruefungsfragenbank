# Historical examination archive

The coordinator needs to find and print archived examination documents by year, specialty and AP/ZP, including ranges such as 2023–2025. Add a direct navigation entry with simple year-range, specialty and exam-type filters. Default to practical examination documents and relevant attachments; other components remain available via an explicit filter. Unknown years remain visible separately and are never guessed from a conflicting filename.

Group documents by source year, specialty, exam type and an explicit date if available. These are archive collections, not assertions that every document belonged to one complete actual exam session. Show source counts, PDF availability, filenames and metadata provenance. Preserve historical original files and layout. Current edited bank task snapshots must not substitute for original historical text.

A coordinator-only export downloads the selected collection(s) as ZIP: merged printable PDF per collection, individual original files, supporting attachments, and a readable manifest of files and missing print copies. Merge without resizing pages; by default each source starts on a front side, adding blank reverse pages when necessary. Missing/corrupt bytes must never produce a silent incomplete download. Missing PDF coverage must be prominently labelled, while available original files remain downloadable. Group accounts receive neither original assets nor export actions.

Protected PDF print copies are prepared from existing original Word conversions, matched to original source hashes, and linked through existing source attachment IDs. No originals or print copies enter public GitHub. No task, exam or use-history mutations. Browser generation uses bundled pdf-lib; no external conversion service.
